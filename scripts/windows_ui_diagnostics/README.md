# Windows UI diagnostics

These scripts are manual experiments for inspecting Windows desktop and File
Explorer UI Automation state. They are not part of FileKiller's runtime or
automated test suite.

Most scripts require the optional `uiautomation` package. `mouse_tracker.py`
requires the optional `pynput` package. Run them individually from the project
root when investigating Windows integration; neither dependency is required to
run FileKiller.
